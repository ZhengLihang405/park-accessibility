# 城市公园绿地服务可达性分析（XX市）

## 背景
评估城市公园服务是否均衡，识别公园服务盲区，为新增绿地选址提供参考。

## 数据来源
- OpenStreetMap（Geofabrik / BBBike），下载日期：2026-xx-xx
- WorldPop 人口栅格（可选）

## 方法
1. 提取公园要素，投影到 UTM 坐标系
2. 500 m 缓冲区生成服务范围
3. 空间判断建筑质心是否被覆盖
4. 统计覆盖率，识别盲区
