# 城市公园绿地服务可达性分析（厦门本岛）

## 背景
评估厦门本岛公园服务是否均衡，识别公园服务盲区，为新增绿地选址提供参考。

## 数据来源
- OpenStreetMap（BBBike提取，范围 118.04-118.20E，24.42-24.56N），下载日期：2026-10-30

## 方法
1. 从 landuse 图层提取公园绿地（recreation_ground、grass、flowerbed），共 71 块
2. 投影到 UTM 坐标系，生成 500 m 缓冲区作为服务范围
3. 将 5538 栋建筑转为质心点，判断是否落入服务范围
4. 统计覆盖率，识别盲区

## 主要结论
- 公园 500 m 服务范围面积约 26.04 km²
- 建筑覆盖率仅 26.4%，约 73.6% 的建筑位于盲区
- 公园服务集中在北部大型绿地周边，中部、东部建成区存在明显盲区，可作为新增公园或口袋公园候选区域

## 局限与改进
- OSM 公园标注不完整，结果为基于 OSM 的估算
- 草地、花坛口径较宽，后续可加面积阈值
- 直线缓冲未考虑真实步行路径，可用 osmnx 路网改进
- 未结合人口数据，可用 WorldPop 计算服务人口比例
